# 趋势闪崩每日预警系统 — 设计方案

> 目标:对一份 watchlist(黄金、热门个股、ETF)做**每日**脆弱度评估,在趋势性品种发生"闪崩式回撤"之前给出分级预警,用于**调节仓位与对冲**,而非择时进出。

---

## 0. 设计哲学(先把目的本身想清楚)

**什么是"趋势闪崩"。** 它是一个原本处于强趋势中的品种,在短时间内(1–3 个交易日)发生大幅回撤,且驱动力主要不是新的基本面信息,而是**拥挤的、加杠杆的单边持仓被迫平仓**——保证金追缴、做市商负 gamma 对冲、波动率目标策略去杠杆、趋势跟随者止损、杠杆 ETF 机械再平衡。它的定义性特征是:**"木头有多干"比"火花是什么"重要得多。**

**因此系统的本质不是预测火花,而是度量木头的干燥程度。** 它每天对每个品种输出一个**条件脆弱度**,而不是一个"会/不会崩"的二元判断,更不是"几号崩"的时点预测。这是你上一轮"催化剂可替换"洞见的工程化。

**输出形态必须是连续的风险旋钮,不是开关。** 这是针对一个已知的行为风险刻意设计的护栏:低波动的 complacency 状态可以持续很久,负 gamma 也不必然崩。如果把它当二元择时信号,它会反复误报,而每一次误报都会诱发不必要的交易冲动。所以它的输出永远是"降多少仓位 / 给哪些品种买保护",不是"清仓 / 满仓"。

**诚实地界定它能做什么。** 这个系统能做到:(1) 显著降低你在最危险品种上的回撤暴露;(2) 把"我有预感"升级为可打分、可校准的过程。它做不到:预测崩盘时点、预测崩盘幅度、消除误报。任何声称能做到后者的设计都是在生成事后自洽的故事。

---

## 1. 闪崩的解剖(因果模型)

闪崩需要三种要素**同时**具备。把它们想成乘法关系而非加法:任何一项接近零,系统就难崩;三项都高,才是教科书式的闪崩温床。

**Pillar A — 拉伸度 / 势能(Extension)。** 趋势跑了多远、多陡、多单边。缓慢上行不会闪崩,垂直拉升才会。这是积累的势能。

**Pillar B — 拥挤度与杠杆 / 燃料(Crowding & Leverage)。** 有多少人朝同一方向押注、且带杠杆。这是最难测但最重要的一项,需要用代理变量拼出来。

**Pillar C — 脆弱性与对冲反身性 / 缓冲的倒数(Fragility)。** 下跌时有多少机械性卖压会被自我强化。做市商负 gamma 会"越跌越卖",这是把普通卖单放大成踩踏的反身性引擎。

**点火邻近层(Ignition Proximity)。** 在三大支柱之上,再叠加一层"离引爆有多近":离 gamma 翻转点的距离(多小的下跌就让做市商转为放大)、离关键均线/大 OI 行权价/CTA 止损位的距离、以及未来 1–3 日的事件日历(财报、Fed、CPI、NFP、OPEX、解禁)。一个高脆弱度品种**且未来几天有已知催化剂**,警报级别要高于同样品种在平静的一周。注意:日历不是用来预测火花,而是用来**调度注意力和提高当日权重**。

**合成逻辑(为什么用乘法/门控而非简单求和)。** 简单求和会让单一高分项(比如只是涨多了)主导,产生大量误报。正确的做法是要求**共现**:`脆弱度 ≈ f(A) × f(B) × f(C)`(几何平均或门控乘积),再乘以一个市场级系统性因子。只有"极度拉伸 + 拥挤多头且无空头缓冲 + 做市商负 gamma"三者叠加,分数才真正拉满。

| 信号 | 衡量什么 | 数据源 | 滞后 | 覆盖 |

### 两个原创特征(这套设计的脊梁)

**1. "利好涨不动"衰竭探测器(Reaction Residual)。** 把你这次对博通的观察形式化:在一个正面催化剂日(财报超预期、对该品种有利的宏观),计算 `反应残差 = 当日实际收益 − 按 surprise 符号/幅度应有的收益`。残差持续为负 = 边际买盘力竭 = 趋势晚期。这是你定性判断里信息量最高的一条,值得做成显式特征,并在事件日提高权重。

**2. 主题相关性级联探测器(Cluster Correlation)。** 当一组品种(如全部 AI 半导体,或 EWY 与三星/SK 海力士)的滚动相关性飙升、同涨同跌时,对其中一个的冲击会级联到全组。上升的组内相关性是该主题的系统性脆弱信号——它同时解释了 6/5 的半导体集体闪崩和你观察到的韩国指数联动。把 watchlist 按主题分簇,监控每簇的相关性与"共同回撤"概率。

### 系统性闸门(市场级乘子)

即使你关注的是单品种,也需要一个市场级闸门来调制所有品种的基线脆弱度(大盘整体脆弱时,每个品种的基线都该抬升)。用现成的"成品"指标:**FRED 的芝加哥联储 NFCI**、**圣路易斯联储金融压力指数**,加 VIX 期限结构。注意:这些是市场级风险计量,不是你要交易的债券品种,与你"不含债券"的约束不冲突。

## 3. 数据源地图(免费优先,可接受 ≤ $12/月)

整套系统**除了期权数据,几乎全部免费**。期权数据是唯一值得付费的一环。

**全免费层(v0 即可跑):**
- 价格/OHLCV/份额:`yfinance` / Stooq。
- 黄金持仓:CFTC COT,`cot_reports` 包(免费;周二数据周五发,T+3)。
- 个股拥挤:FINRA 空头利率(免费,双周)。
- 系统性闸门:FRED 的 NFCI、金融压力指数(`fredapi`,免费 key,周度)。
- 波动率结构:CBOE 免费延迟数据 + FRED(VIX、SKEW、VIX 期限)。
- 情绪:AAII 多空比(免费周度)、CBOE Put/Call(免费)。
- 事件日历:财报日(yfinance / Finnhub 免费档)、OPEX/Fed/CPI/NFP 日期(可计算/公开)。

**期权数据(三选一):**

| 方案 | 成本 | 拿到什么 | 适用 |
|---|---|---|---|
| **FlashAlpha 免费档** | $0 | 预算好的 net GEX、gamma flip、call/put wall(每标的单一到期日) | 最省心,直接给你算好的 GEX,v0/v1 首选 |
| **Tradier(开户后)** | $0(活跃账户) | 原始期权链(自己算 Greeks/GEX) | 已有/愿开 Tradier 账户;数据干净 |
| **marketdata.app** | ~$12/月(年付;月付 $30) | 实时 Greeks/IV/OI 全链 | 需要全到期日、多品种、可控延迟 |

注:marketdata.app 按 credit 计费,**整条期权链的每个合约消耗 1 credit**,所以对小 watchlist(5–15 个名字)每日 EOD 拉一次完全够用,但别频繁拉全链。ThetaData($25)、EODHD(€20–30)、Polygon 期权($79+)都超预算,不必用。

**核心纪律 — point-in-time 与滞后诚实:** 每个特征都打上真实 as-of 时间戳。GEX 的做市商符号是**估计**不是事实、OI 是 T-1、COT 是 T+3、空头利率是双周。回测和实盘都只能用当时真正可得的数据,否则既骗了回测,也会在实盘把滞后数据当实时用。

## 4. 评分引擎

**归一化。** 每个品种对每个指标算**滚动分位 / robust z-score**(用 trailing 1–3 年窗口,winsorize 去极值)。关键是**相对品种自身历史**做分位,因为"拥挤"是相对概念;NVDA 的"拥挤"和黄金的"拥挤"刻度不同。

**两个互补输出:**
- **(a) 标准脆弱度分(0–100)。** 三支柱分位 → 门控乘积/几何平均 → 乘系统性闸门 → 0–100。直观、可解释。
- **(b) 条件 hazard 估计。** 用一个**校准过的简单模型**(逻辑回归或离散 hazard model),以特征为输入,输出"未来 N 日内发生 ≥X% 回撤的条件概率"。这是统计上诚实的"预测"版本——一个条件风险率,不是点预测。两者并行:(a) 给人看、(b) 给纪律用。

**横截面排名。** 把 watchlist 内所有品种相互排名、并与市场排名。一个在"拉伸+拥挤"上是离群点的品种,比绝对分数更危险。相对性,而非只看绝对值。

**变化检测。** 报警基于**跨越阈值**和**快速恶化(Δ分数)**,不是每天的绝对水平。一个分数从 40 三天内冲到 70 的品种,比一个长期稳在 65 的品种更值得喊。

## 5. LLM 层(便宜模型即可,token 不计成本)

**铁律:LLM 消费已算好的特征,绝不发明数字。** 所有数值来自确定性管道,LLM 只做语言、解释、扫描和质询。这道隔离防止幻觉污染信号。

**职责:**
- **叙事简报:** 把当日脆弱度分解翻译成可读的简报,解释每个被标记的品种**为什么**脆弱、**什么机制**会驱动其平仓。
- **催化剂标注:** 扫描新闻/公告/日历,给每个名字挂上未来催化剂——这是廉价 LLM 批量扫标题最划算的用法。
- **反应残差定性读数:** 在事件日对"利好涨不动"做文字判断。
- **误报自述:** 给每条警报附上"如果这是误报,我应该看到什么 / 什么会证伪今天的判断"。

**多智能体红队(契合你在做的 orchestration,且 token 免费):** 让一个"多头辩护人 (Bull's Advocate)"和一个"脆弱鹰派 (Fragility Hawk)"就每个被标记的品种辩论,一个 orchestrator 汇总分歧。因为 token 不计成本,你可以跑 ensemble + 每日批判循环,但要用**阶段化轮次**防止 token 烧循环(这正是你那个 multi-LLM 应用里在解决的问题)。

**护栏:** 反幻觉(数字只读)、反过度自信(每条结论必须附基础概率,见 §7 的误报账本)。

## 6. 触发与分级处置

分数带 → 风险动作。**全部表述为仓位/对冲,而非进出。**

| 分数带 | 状态 | 建议动作(连续旋钮) |
|---|---|---|
| 0–40 | 正常 | 维持 |
| 40–60 | 关注 | 收紧心理止损、暂停加仓 |
| 60–75 | 警戒 | 减仓 X% 或买入便宜的保护(OTM put) |
| 75+ | 高危 | 降到核心仓位、加对冲 |

**警报卫生:** 只在**状态切换**时推送;其余时间出每日 digest。避免天天喊狼来了导致你脱敏。

**每条警报都配一个"证伪伴侣":** "什么情况会让这次预警变成误报" + "这个分数带历史上 10 日内真的闪崩的比例是 X%"(来自 §7)。这同时服务于校准和你的行为纪律——它持续提醒你基础概率。

## 7. 回测与持续自校准(不可跳过)

这一步是这套系统是"工具"还是"故事生成器"的分水岭。我已经强调过两次,这里给出可执行的方法。

**闪崩的操作化定义。** 例如:此前 M 日处于上升趋势(价格在 200 日均线上方且 N 日涨幅为正)的品种,在 ≤K 个交易日内从近期高点回撤 ≥X%。参数要在事件库上标定。

**事件库。** 你已观察到的:EWY 三月回撤、年初黄金白银历史级冲顶闪崩、SNDK 多次回撤、这次 6/5 半导体集体闪崩;再补一批更广的历史单股/ETF 闪崩样本,扩大统计基数。

**评估指标:** 分数在事件前 T-5 窗口是否真的抬升?各分数带的 precision/recall、**基础概率(base rate)**、reliability diagram(校准曲线)、以及**误报率(FPR)**——高分却没崩的频率才是你真正要盯的数字。还要看**领先时间分布**(提前几天报警)。

**Walk-forward,严格 point-in-time,无 lookahead。** 尊重所有数据的发布滞后。

**实盘误报账本(live ledger)。** 系统记录每天每个品种的分数,事后回填真实结局,持续计算自己的 running precision,并**在每条警报旁显示当前可信度**(如"该分数带近一年内 10 日内闪崩的命中率 22%")。回测永不停止,它变成实盘的持续校准——这是对你择时倾向最硬的一道防火墙。

## 8. 工程架构

**管道(每日盘后定时任务):** 抓取各源(幂等、缓存原始数据)→ 写入特征存储(每品种每日,带 as-of 时间戳)→ 归一化与评分 → 变化检测 → LLM 生成简报 → 推送(邮件/Telegram,仅状态切换时)→ 回填结局到账本。

**技术栈建议:** Python;`cron` 或你的定时 agent 做调度;SQLite 或 parquet 做特征存储;`fredapi` / `cot_reports` / `yfinance` / 期权 API 客户端做接入;轻量逻辑回归用 `scikit-learn`。

**可观测性:** 每次运行记录数据新鲜度与缺失;缺数据时降级而不是静默出错。

## 10. 已知局限与失败模式(必须时刻清醒)

- **误报是结构性的。** 低波动 complacency 能持续数月;负 gamma 不必然崩;高分常常无事发生。这是为什么输出是连续旋钮而非开关。
- **滞后陷阱。** COT 是 T+3、OI 是 T-1、空头利率双周、margin debt 月度——别让滞后数据伪装成实时。
- **代理变量不完美。** GEX 的做市商符号是估计;单股拥挤度缺乏黄金那样干净的 COT;13F 是季度且滞后。
- **元风险(最该警惕的)。** 这个系统本身可能变成你重新开始择时的新借口。它的全部价值在于**降低最危险品种的回撤暴露**,而不是给你一个进出场信号。把它接到仓位旋钮上,守住这条线。
