     IBKR Options Adapter — Implementation Plan

     Context

     The OpEx Risk Agent currently supports two options data providers
     (hongquant/flows/opex_risk.py:41-46):

     - yfinance — free but slow (one HTTP round-trip per expiry, no Greeks, OI
     often missing for index ETFs); used today for dev.
     - Polygon.io — fast and complete but ~$30+/month for the tier that returns
     IV/Greeks/OI.

     The user holds ~$430k in IBKR and is already paying broker commissions;
     adding OPRA (~$1.50/month non-pro) gives live, batched options snapshots
     over a single TCP connection — strictly faster than yfinance and free
     relative to Polygon. This plan adds an IBKR adapter alongside the existing
     two (no removal), and documents the one-time TWS/Gateway + market-data
     setup needed before the agent can talk to IBKR.

     Resolved decisions:
     - User will subscribe to OPRA before first run; adapter targets live data
     with reqMarketDataType(1) and falls back to delayed (3) when
     env-configured.
     - Recommendation: IB Gateway, live, port 4001 — see "TWS vs IB Gateway"
     below. Code default kept at IBKR_PORT=7497 (paper TWS) so existing
     tests/dev still work; production switches via .env.
     - Keep yfinance and Polygon adapters intact; IBKR becomes a third
     selectable provider.

     TWS vs IB Gateway — recommendation

     Use IB Gateway, live (port 4001), with a dedicated IBKR_CLIENT_ID.

     Why live over paper: Market data subscriptions are tied to the live
     username on IBKR; paper sessions only inherit subs if you've explicitly
     enabled "Share market data" in Account Management. Using the live login is
     one fewer configuration step. The adapter is read-only — it never places
     orders — so connecting to the live socket carries no execution risk. Still,
      set readOnlyApi=true in Gateway's API config as a belt-and-suspenders
     measure.

     For weekend dev / smoke tests when Gateway isn't running, fall back to
     --provider yfinance.

     ---
     User-side setup steps (one-time)

     1. Install the optional dep (already declared in pyproject.toml:35):
     uv sync --extra ibkr
     2. Subscribe to OPRA in IBKR Account Management → User Settings → Market
     Data Subscriptions:
       - "US Securities Snapshot and Futures Value Bundle" (free if commissions
     ≥ $30/mo, else $10/mo) — covers SPY/QQQ stock quotes
       - "US Equity and Options Add-On Streaming Bundle" or "OPRA (US Options
     Exchanges)" — ~$1.50/month non-pro
       - For SPX/NDX index options: add "CBOE One US Add-On"
     3. Configure IB Gateway (download from interactivebrokers.com if not
     already installed):
       - File → Global Configuration → API → Settings
           - Enable ActiveX and Socket Clients: ✅
         - Socket port: 4001 (live) or 4002 (paper)
         - Master API client ID: leave blank
         - Read-Only API: ✅
         - Trusted IPs: add 127.0.0.1
       - Save, restart Gateway, log in with live credentials
     4. Set .env:
     OPTIONS_DATA_PROVIDER=ibkr
     IBKR_HOST=127.0.0.1
     IBKR_PORT=4001
     IBKR_CLIENT_ID=17
     IBKR_MARKET_DATA_TYPE=1        # 1=live, 2=frozen, 3=delayed,
     4=delayed-frozen
     5. Smoke test (Gateway must be running and logged in):
     uv run python -m hongquant.flows.opex_risk --mode weekly --dry-run
     --provider ibkr --underliers SPY

     Code plan

     New file: hongquant/options/adapters/ibkr_options.py

     Mirrors polygon_options.py contract exactly — same function signature, same
      CHAIN_COLUMNS output (imported from polygon_options to avoid duplication,
     as yfinance_options.py already does on line 15).

     Function signature (matches existing adapters):
     def fetch_chain_snapshot(
         underlier: str,
         *,
         expirations: list[date] | None = None,
     ) -> pd.DataFrame

     Implementation outline:
     1. setup_logging(); read get_settings() for
     host/port/client_id/market_data_type
     2. Lazy import ib_async (raise RuntimeError with install hint if missing)
     3. Open one IB() connection per call (sync wrapper; ib_async exposes
     util.run/connect)
     4. ib.reqMarketDataType(settings.ibkr_market_data_type)
     5. Qualify underlier contract:
          - "SPX"/"NDX"/"VIX"  -> Index(symbol, exchange="CBOE", currency="USD")
            (NDX uses "NASDAQ"; map per UNDERLIER_EXCHANGE below)
          - others             -> Stock(symbol, "SMART", "USD")
        ib.qualifyContracts(under_contract)
     6. Snapshot spot: ib.reqTickers(under_contract) -> ticker.last or
     marketPrice()
     7. ib.reqSecDefOptParams(symbol, "", secType, conId)
          -> returns expirations (YYYYMMDD strings) and strikes (floats) per
     exchange
        Pick row matching primary exchange (CBOE for index, SMART/CBOE for
     ETFs).
     8. Filter to target expirations:
          - If `expirations` provided: intersect with available
          - Else: front_friday(today), next_friday(today)
        Filter strikes to a sensible band around spot (e.g. ±15%) to keep
     request count down.
     9. Build Option contracts:
          [Option(symbol, exp_str, strike, right, exchange, "100", "USD")
           for exp, strike, right in product(target_exps, strikes_band,
     ["C","P"])]
     10. ib.qualifyContracts(*opts) — drops any non-tradable strikes
     11. Pace: chunk into batches of <= 50, call ib.reqTickers(*batch) per chunk
         (reqTickers returns when all snapshots arrive or after 11s timeout
     each).
         Greeks come via ticker.modelGreeks / ticker.bidGreeks /
     ticker.askGreeks;
         OI via ticker.callOpenInterest / ticker.putOpenInterest on the
     underlying *or*
         per-contract via ticker.callOpenInterest (depends on tick type
     100/101).
     12. Normalize each ticker into the CHAIN_COLUMNS row dict, identical to
     polygon adapter.
     13. ib.disconnect() (in finally block to avoid socket leaks)
     14. Return DataFrame[CHAIN_COLUMNS], sorted by (expiration, strike,
     option_type).

     Constants:
     UNDERLIER_EXCHANGE: dict[str, tuple[str, str]] = {
         # symbol -> (secType, exchange)
         "SPX": ("IND", "CBOE"),
         "NDX": ("IND", "NASDAQ"),
         "VIX": ("IND", "CBOE"),
     }
     _DEFAULT_STRIKE_BAND_PCT = 0.15   # ±15% around spot
     _CHUNK_SIZE = 50                  # IBKR pacing limit
     _REQ_TIMEOUT = 15.0               # seconds per ticker batch

     Error handling / fallbacks:
     - Connection refused → RuntimeError("IB Gateway not reachable at 
     {host}:{port} — is it running and logged in?")
     - No market data subscription → IBKR returns NaN IV/Greeks; log a warning
     once per underlier, do not raise — downstream metrics handle NaN via
     iv_rank=None / oi_vs_baseline=None.
     - Empty chain → return empty DataFrame with CHAIN_COLUMNS (matches yfinance
      adapter behavior on line 170-201).

     Also export:
     def fetch_previous_day_oi(underlier: str) -> pd.DataFrame:
         return fetch_chain_snapshot(underlier)
     to maintain parity with polygon_options.py:141-143 and
     yfinance_options.py:227-229.
